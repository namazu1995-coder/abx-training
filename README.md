# 抗菌薬選択トレーニング

初期研修医向け、エンピリック抗菌薬選択トレーニングアプリ。6症例(市中肺炎／複雑性腎盂腎炎／蜂窩織炎/壊死性筋膜炎の鑑別／急性胆管炎／ペニシリン・セフェムアレルギー／発熱性好中球減少症)を通じて、抗菌薬の「暗記」ではなく「判断プロセス」を段階的に学ぶ。

サーバー・APIキー不要、オフラインで動作する単一HTMLファイル。スマホ・タブレット・PCいずれでも利用可能。

## ローカルでの確認方法

`abx-training.html` をブラウザで直接開くだけで動作する(ダブルクリック、またはブラウザにドラッグ&ドロップ)。

```bash
start abx-training.html
```

## 医師が確認すべき医学的内容(要レビュー)

各症例の数値・薬剤選択は実在するガイドライン・論文をWebSearch/WebFetchで直接確認して記載しているが、以下は施設プロトコルや最新版ガイドラインとの整合性を医師の目でチェックしてほしい箇所:

1. **症例1(市中肺炎)**: 細菌性/マイコプラズマ肺炎鑑別6項目のカットオフ(4項目以上)、A-DROPの重症度区分
2. **症例2(複雑性腎盂腎炎)**: 治療期間14日間(JAID/JSC2015準拠。IDSA/ESCMIDでは感受性のあるフルオロキノロンで7日間への短縮を支持するデータもある)、AmpC過剰産生菌に対するセフェピムのMICカットオフ(2/4μg/mL)、ABPC/CEZ/CMZの具体的な用量
3. **症例3(蜂窩織炎)**: LRINECスコアのカットオフ(6点/8点)と実際の感度(近年の検証では感度40%台程度との報告があり、除外目的での使用には限界がある旨を本文に明記)
4. **症例4(急性胆管炎)**: TG18重症度(Grade I〜III)別の具体的用量、ドレナージ後4〜7日間という治療期間
5. **症例5(β-ラクタムアレルギー)**: 側鎖類似性による交差反応率(全体で約2%、側鎖類似時16%程度という数値)
6. **症例6(発熱性好中球減少症)**: MASCCスコアのカットオフ(21点)、セフェピム等の腎機能に応じた用量調整(本文中でも「施設プロトコル・薬剤部に確認」と明記し、具体的な調整幅はあえて断定していない)

## 技術メモ

- 単一HTMLファイル(`abx-training.html`)。外部依存はGoogle Fontsのみ(CSPで許可済み、それ以外は`'self'`/`'none'`、`connect-src 'none'`で通信を行わない)
- 進捗・自由記述の下書きは`localStorage`に保存(キー: `abx_progress_v1`, `abx_drafts_v1`)。プライベートブラウズ等でストレージが使えない場合は画面に警告を表示する
- 復習フラグ(自己評価「一部抜けた」「ほぼ言えなかった」)が付いた症例だけを絞り込める「復習」ボタンをホーム画面に表示
- 起動時に症例データの整合性(ID重複・必須フィールド欠落など)をチェックし、異常があれば`console.warn`に出力する
- 各症例の参考文献は実在・内容一致をWebSearch/WebFetchで検証した一次資料(学会ガイドライン、査読付き論文)のみを掲載。存在しない/内容と無関係な引用は載せない
